IAEA Live Chart API

Everything NSRgpt can build on nds.iaea.org/relnsd/v1/data: CSV over plain HTTP, no key, one nuclide or one fission parent per request. Sources: ENSDF, AME2020, NUBASE2020, the IAEA moments tables, Betashape 2.2 spectra, JEFF-3.1.1 fission yields. My top five are marked; all five are built: /viz/fission-yields, /viz/explorer, the measured heat in /viz/particles, /viz/radiation and /viz/gamma-lines.

How it's stored and served

  1. Raw pulls, as served, in the lake: s3://govblock-lake-638175140432/lake/v1/nsr/iaea-livechart/2026-11-06/, beside the NSR export.
  2. Each chart gets a compact JSON built from the raw files, served from the worker's static assets and loaded only by its own page; large sets split per parent or per element.
  3. The live site never calls the IAEA: no added latency, nothing breaks if their server is down.

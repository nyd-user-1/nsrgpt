ReleaseOne published version of a family, as ENDF/B-VIII.0. The lake names it as JANIS labels it, without “ENDF/” (B-VIII.0).VersionB-VIII.0
MaterialOne target's evaluation inside a release, numbered by MAT (U-235 is 9228).Nuclide, isotope. The chart says material.B-VIII.0
Section (MF/MT)One block of a material: MF is the File number (the kind of data), MT the reaction (18 fission, 102 capture).“MF 3” and “File 3” are the same. The chart says File.Parsed tables
EvaluationAn evaluator's recommended values for a material, from measurements and models.Evaluated data, as against EXFOR's measured data.Evaluated reaction libraries
Original filesThe publisher's files exactly as released, kept unchanged.Raw, tape, source files. The chart says original files.Original files
PackageJANIS's own copy of a release (.jpk); its neutron File 3 is processed, not the evaluation.janis/data, .jpkJANIS packages
Parsed tableAn Athena table holding a release's contents as rows, one partition per release.Lake tableParsed tables

ResonanceA sharp peak in a cross section where the nucleus has a level; File 2 stores its parameters.Resonance parameters, MF 2endfb_res_ranges

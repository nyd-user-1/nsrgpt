How

  2. The boxes (scripts/iaea/box/): EC2 m7i-flex.large for Chrome, t3.small for the Wayback lane, reached through SSM, each ends itself after 4 hours. mirror.py runs real Chrome under Xvfb, one browser per proxy line, one queue and one rate limit per site. wbget.py streams Wayback copies straight to S3.
  3. Manifests: scripts/iaea/manifest.sh merges each folder's Lambda and box records into one manifest.json: every file with its source URL, bytes, sha256 when known, and for Wayback copies the snapshot date; not taken with reasons; dead links; spend. This page: scripts/iaea/inventory.sh.
  4. NNDC: scripts/nndc/crawl.py walked the site, list.py added the archive and data-app file lists, pull.py sent 3,508 files through Lambda nsr-fetch: 59 GB in 5 minutes, no errors.

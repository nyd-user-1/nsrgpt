nsr codebase audit

Measured 2026-11-04 from /Code/nsr. ~30,500 lines of TS/MJS · 56 components · 26 pages · 63 scripts · 26 SQL files · 18 Vercel functions · 48MB of public data.

BNLgpt

Search, chat, and browsing over the Nuclear Science References corpus and the related NNDC databases (ENSDF, XUNDL, EXFOR), using a fine-tuned retrieval stack (NSR-CPT). React 19 + Vite + TypeScript SPA.

Data, as of 2026-11-04

  • Primary store: S3 + Athena. Full export at s3://nsr-lake-638175140432/lake/v1/nsr/nsr-to-lake-2026-11-04/ — 42 parquet tables; 29 queryable in Athena (nysgpt_nsr). 303,568 references (255,315 NSR + 49.5k arXiv/APS), 1.21M typed nuclide links, 20,121 ENSDF datasets for 3,445 nuclides, XUNDL listings, full EXFOR entries, S2/OpenAlex enrichment.
  • Neon is being shut off. sparkling-moon-06542876 has no deployed readers; this repo's api/* functions are the last code that queries it, and they stop working when it goes.
  • NSR-CPT — bge-m3 fine-tuned on 206k expert keyword abstracts + EXFOR links, with a cross-encoder reranker and a frozen benchmark. Four private HF repos under NYSgpt. Details: docs/NSR-CPT-REPORT.md.

Current status

The Vercel deployment (nsr.nysgpt.com) is disabled (402) and the CLI token is dead. The app runs locally with npm run dev; the API layer still queries Neon. To revive: pick a hosting platform, repoint api/* at Athena, build the particle view (docs/sketches/2026-11-04-particle-view.html).

Known constraints

  • Vercel functions use the classic (req,res) signature — web-standard handlers hang here. Unbundled ESM: local imports need .js extensions.
  • Vector queries bind the vector as $1::vector (a join-sourced probe defeats HNSW); SET LOCAL hnsw.ef_search needs sql.transaction.
  • Bulk loads go through psql \copy, never the HTTP driver.

## 7. Operating procedures and limits

- Shared working tree: `git pull --rebase --autostash origin main`, then `git commit -- <paths>` in one step; push only your own commits (detached worktree off `origin/main` when local `main` carries others').
- Type check and lint run on the dev box, not the Mac: upload a tarball to `s3://nsr-lake-613473203863/lake/_work/tc/<name>.tgz`, then via SSM copy `git ls-files` of `/srv/nsrgpt` to a scratch dir, symlink `node_modules`, untar over it, run `tsc --noEmit` and eslint on changed files.
